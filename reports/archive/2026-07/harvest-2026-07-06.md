## Skill 候選

### 🟡 Moderate — `demo-walkthrough-pages`（提案用互動 demo 頁管線）— 建議 hold

- **Purpose**：固化「B2B/B2G 提案 demo 頁」產線：(a) 情境腳本（誰、按什麼、看到什麼）→ 多畫面 walkthrough HTML（假資料、單檔可開）；(b) build script（build.js/py）統一產版與版號（`_v2` 疊代）；(c) headless Chrome 截圖鏈自檢；(d) PNG 直送 office-pptx / 提案文件。
- **Trigger**：「做個 demo 給客戶看」「demo 頁」「操作示意」「提案要放畫面」。
- **Category**：`docs`（提案產出物）或 `frontend`
- **Rationale**：Session 1、2 完整走了兩輪（YouBike 動線、訴願填寫/預評估），形狀一致；但**兩次都在同一專案（新北案）**，n=1 客戶。與既有 skill 有重疊：`mockup`（interactive HTML fidelity）、`gstack-design-html`（HTML 畫面）、`chimesflow-design`（設計 SoT gate）——缺的 delta 只有「情境 walkthrough + 截圖鏈 + 餵 deck」這層黏合。**等第 2 個客戶/專案出現同需求再抽**，屆時評估是獨立 skill 還是併入 `mockup` 的一個 mode（符合 [[skill_structure_preference]] 的 orchestrator+data 原則）。

### 🟡 Moderate — `gdrive-deck-miner`（舊 deck 內容開採 → 新演講素材）— 建議 hold

- **Purpose**：把 Google Drive 上的歷史簡報當素材庫：搜尋相關 deck → `getGoogleSlidesContent` 抽每頁文字/講者備註 → 按主題歸併 → 產出新演講的 outline 草稿與「可重用頁清單」。
- **Trigger**：「我有一個演講，之前講過類似的」「把舊簡報的內容撈出來」「用以前的 deck 當底」。
- **Category**：`docs`
- **Rationale**:Session 4 完整示範（數位孿生演講 ×7 次 gdrive MCP 呼叫 → outline_deck1.txt）。既有 skill 都不覆蓋這個角度：`gdrive-to-skills` 是把文件轉知識 skill、`slide-template-extractor` 抽的是**樣式**不是內容、`slide-workflow` 假設從零寫大綱。但 **n=1 session**，且演講備料頻率未知——若下季再出現一次「舊 deck 開採」就升 Strong。
