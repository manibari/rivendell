## Skill 候選

### Weak — `url-unwrap`（解開包裝/短網址）

| 欄位 | 內容 |
|------|------|
| **Purpose** | 解開 Outlook safelinks（`*.safelinks.protection.outlook.com/?url=...`）、`pse.is` / `bit.ly` 等短網址，還原真實目標 URL 後再 WebFetch |
| **Trigger** | 貼上 safelinks 包裝網址或短網址、需要還原真實連結時 |
| **Category** | `quality` 或 `backend`（小型工具） |
| **Rationale** | safelinks 的 `url=` 參數只需 URL-decode 即可還原；短網址需 `curl -sIL` 看 `Location`（注意 CLAUDE.md 已記載 scraper 預設 `allow_redirects=false`，需明確跟隨）。**但 n=1，模式太單薄** — 一條 `urllib.parse.unquote` + `curl -IL` 即可解決，抽成 skill 的維護成本高於收益。建議先記入 learnings，累積到 2+ 次再評估。 |

## 建議行動

1. **本批不抽新 skill**：無達 Strong / Moderate 門檻的候選。
2. **記 learnings（generic vault）**：safelinks 解包一行指令片段
   ```bash
   # safelinks: 取 url= 參數並 decode
   python3 -c "import urllib.parse,sys;print(urllib.parse.parse_qs(urllib.parse.urlparse(sys.argv[1]).query)['url'][0])" "<safelinks-url>"
   # 短網址: 跟隨 redirect 看終點（scraper 預設不跟隨）
   curl -sIL -o /dev/null -w '%{url_effective}\n' "<short-url>"
   ```
   → 寫入 `~/.claude/learnings/LEARNINGS.md`，category: `best_practice`，待第 2 次出現再促進。
